## [2026-07-08] 进程隔离根治stream卡死 + 去掉冷却期 + 可视化行标记

**Commit**: 待提交

### 新增

1. **stream_worker.py 子进程**（`visualizer/backend/app/services/stream_worker.py`，新建）
   - 独立进程中执行 gsbag 读帧 + ffmpeg 编码，fMP4 chunks 写 stdout
   - 父进程从 pipe 读取并通过 StreamingResponse 转发给浏览器
   - 客户端断开后父进程 kill 子进程，OS 回收所有资源（fd/mmap/gsbag 全局锁）
   - 彻底解决 gsbag 全局锁不释放导致下次请求卡死的问题

2. **可视化行标记**（`AgentPanel.jsx`）
   - 点击「播包可视化」后，该行背景变为 `#e6f7ff`（浅蓝）+ 左侧 3px 蓝色边框
   - 使用 `visualizedRows` Set 记录已点击行的全局索引（跨页保持）
   - 避免用户重复可视化同一行结果

### 修复

1. **stream 卡死根治** — gsbag C 层读帧线程卡在 IO 时，Python 层 cleanup 无法释放全局锁。改为进程隔离架构：子进程被 kill 后，OS 保证回收所有资源（fd、mmap、进程级锁），不再依赖 Python 层 cleanup
2. **去掉播放器关闭后的 1.5 秒冷却期** — 进程隔离后不再需要等待旧资源释放，关闭播放器后可立即点击下一行可视化，按钮不再变灰

### 重构

1. **video.py stream 端点** — `/stream-hevc` 和 `/stream-h264` 改为 `subprocess.Popen` 启动 stream_worker.py，替代原来的进程内 `extract_topic_hevc_stream()` / `extract_topic_h264_stream()`
2. **前端移除 visualizeCooldown** — 删除 cooldownTimerRef、startVisualizeCooldown 函数和相关 UI 禁用逻辑
