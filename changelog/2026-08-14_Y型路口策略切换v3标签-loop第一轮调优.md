# Y型路口策略切换 v3 标签（Loop 第一轮调优）

> 日期：2026-08-14
> Commit：见 CHANGELOG.md 索引
> 分支：feature/gen-sql-two-round

## 背景

用户人工标注了 Y型路口 策略评测集（20 窗口 / 16 bag，4 pass / 16 fail）。
v2 标签在评测集上正确率仅 4/20。本轮建立端到端 loop：
评测集取证 → mage-vl 视觉归因 → 候选规则快速回归（eval harness）→
抽样防过拟合验证 → 全量重刷回写 → 策略切换。

## 失败机制归因（mage-vl 视频复核 16/16 fail 窗口）

1. **高架桥上下桥分岔**（约 12 个）：桥上桥下两层信息压成同一平面，
   地图 1→2 分叉拓扑在分层的平行道路/下桥匝道处同样成立 → 误报
2. **主辅路分岔**（1 个）：主路 link 一分二，一支为辅路（formWay 7）
3. **十字路口残留**（2 个）：路口排除逻辑未覆盖的边界情况
4. 地图无高程字段、车端 split_merge_tag 本批次全为 none，
   无法直接判桥层，只能用结构代理信号

## v3 新增规则（在 v2 基础上叠加）

| 规则 | 内容 | 机制 |
|------|------|------|
| cls_le2 | fork roadClass ≤ 2 剔除 | 快速路/高速主线分叉多为分流 |
| main_side | fork formWay=1 且分支含 formWay=7 剔除 | 主辅路分岔非 Y 型 |
| fw15_slow_long | 分支 formWay=15 且（长度≥2000m 不降速）或（fork 非主路且长度≥1000m 限速≤fork）剔除 | 平行分层道路 / 下桥匝道 |
| spd_asym | 同 formWay 双分支限速差 ≥20 剔除 | 一侧实为降级分流 |
| parallel_pair | 双分支长度均≥800m 且均不降速剔除 | 平行道路分层 / 主线分延 |

## 效果

- 评测集：4/20 → **19/20**（4 个 pass 全部保留）
- 唯一残留 fail（fork 174800207，formWay=2 分叉）与某 pass 案例结构完全相同，
  拒绝为其单独加规则以防过拟合
- 抽样防过拟合：随机 30 个 v2 正样本 bag，12 个翻转，
  mage-vl 复核 6 个翻转 fork 全部剔除正确（期间发现并修复 1 条真 Y 误杀：
  fw15_slow_long 放宽主路 fork 豁免、spd_asym 收紧为同 formWay 分支间）
- 全量正样本：4,081 → 1,876 bag（26.4% → 12.1%）
