> 日期：2026-08-18
> 范围：`visualizer/frontend/src/` 全面重构（P0 交互修复 + P1 结构拆分 + P2 功能补齐 + 视觉统一）
> 构建验证：`react-scripts build` 通过，0 warning

## 背景

前端此前是 5670 行单体代码：`AgentPanel.jsx` 一个文件 2715 行（49 个 useState、211 处内联 style），
`authFetch` 在 `App.js` 和 `AgentPanel.jsx` 各抄一份，裸 `alert()` 报错，token 拼在 URL query 里，
MSE 流播放逻辑重复实现两处，宽度写死 1200px 无响应式。本次重构**不改变任何交互行为与 API 协议**。

## 各项变更明细

### P0 交互体验
1. **alert() 全灭** → `useToast()`（success/error/warning/info，自动消失，最多堆 5 条）。
   `window.confirm`（删除策略、同步产线）和 `window.prompt`（手动输入 bag 路径）保留——它们是输入/确认而非通知。
2. **查询取消按钮**：LLM 查询/流式查询进行中，QueryBar 出现「✕ 取消」，
   abort 底层 fetch/SSE（AbortController 原本就有，这次把 UI 接上）；
   AbortError 不再被当作错误展示。
3. **token 不再拼 URL**（fetch 场景）：`stream-hevc`/`stream-h264` 的 MSE 流走 `authFetch` 的
   Authorization header，URL query 里的 `?token=` 已移除。
   仅 `<video src>`（无法设 header）保留 `addTokenParam()`，已集中在 `api.js` 并注明用途。
4. **结果表格三态**：loading 骨架屏（`.skeleton` CSS 动画）/ 空态虚线卡片 / 错误红条。
5. console 诊断残留（`[HEVC诊断]` 等 18+ 处）清理，只保留真正的 error 日志。

### P1 可维护性
6. **AgentPanel 拆分**：2715 → ~700 行，子组件见上方结构图。
7. **authFetch 收敛单例**：`src/api.js`，`App.js`/`AgentPanel.jsx` 的重复实现删除；
   `BevViewer`/`MultiVideoGrid` 改为 import（不再收 `authFetch` prop）。
8. **样式收敛**：`theme.js` 统一配色（primary #1677ff 系）/圆角/阴影/按钮变体，
   新代码禁止再手写颜色值；布局微调才允许内联。

### P2 功能补齐
9. **历史查询面板**（docs/ARCHITECTURE.md Phase 4 待办项 ✅）：
   - 纯前端 localStorage 实现（key=`scenesql_query_history`，上限 50 条，按 SQL 去重），**零后端改动**
   - 记录时机：`/query`、`/query-stream`（completed）、`/execute-sql`、`/generate-sql` 成功后
   - 点击条目回填 question + SQL 编辑器；支持清空
10. **响应式**：页面宽度 1200px 写死 → `maxWidth:1400 + clamp() padding`，
    各输入行 `flexWrap`，表格单元格 `maxWidth+ellipsis`（hover title 看全值）。

### 视觉统一
- 卡片：10px 圆角 + 双层柔和阴影；按钮统一 `btn.*` 变体（primary/success/danger/purple/cyan/ghost/outline）
- 输入框统一 focus 蓝边光晕（全局 CSS）；表格斑马纹 + hover 高亮 + sticky 表头/操作列
- 弹窗统一 `modal.overlay/dialog`（毛玻璃遮罩 + 大圆角 + 深阴影）
- 标题从「Rosbag Visualizer」改为「SceneSQL Visualizer」（与登录页一致）

## 行为兼容性声明

- 所有 API 调用路径、payload、SSE 协议（`data: ` 行 / stage 字段）均未改动
- localStorage key 全部保留（token / lastBatchId / lastSelectedTopic），新增 `scenesql_query_history`
- 视频播放链路（MSE/HEVC/H.264 降级、宫格、BEV）逻辑逐行平移，仅做了函数级抽取

## 部署

前端纯静态重构，`cd visualizer/frontend && npm run build` 后按原流程部署（deploy.sh / DSW）即可，无新依赖。
