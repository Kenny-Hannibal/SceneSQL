# BEV视图片段模式：只播SQL片段而非整个bag

## Commit
- `feat: BevViewer片段模式—只播startTsNs~endTsNs范围帧 + 批量ts查询API + 预构建ts索引`

## 变更内容
1. BevViewer 改为片段模式：当传入 startTsNs/endTsNs 时，只播放对应时间范围内的帧，而非整个 bag
2. loadInfo 时调新API `/fusion-map-frames-by-ts-range` 一次获取 startFrameIdx 和 endFrameIdx（ts索引只构建一次，避免两次API调263秒×2）
3. get_fusion_map_info 预构建ts索引缓存，避免后续find_frame_idx_by_ts首次4分钟卡顿
4. 新增后端API `/api/bag/fusion-map-frames-by-ts-range` 支持批量ts→frame_idx查询
5. 播放逻辑到 endFrameIdx 自动停止，进度条 slider 范围限定在 [startFrameIdx, endFrameIdx]
6. 帧计数器显示"片段帧: X / Y"而非"Frame: X / totalFrames"
7. 顶部显示片段时间范围（秒），索引期间显示"正在索引帧..."提示

## 涉及文件
- `visualizer/frontend/src/components/BevViewer.jsx`
- `visualizer/backend/app/api/fusion_map.py`
